# ปรับแอปให้พอดีกับหน้าจอมือถือ

## สิ่งที่จะปรับ
- จำกัดโครงหน้าหลักและทุกหน้าภายในไม่ให้กว้างเกินหน้าจอ พร้อมตัดการเลื่อนแนวนอนที่ไม่จำเป็น
- ปรับหัวเว็บ ปุ่มเลือกโหมด GPS/กรอกเอง แผนที่ ฟอร์ม การ์ดรายงาน และหน้าผู้ดูแลให้ย่อหรือเรียงลงเมื่อจอแคบ
- ปรับเมนูล่างให้รองรับจำนวนเมนูของผู้ดูแลโดยไม่ดันออกขอบ และเพิ่มพื้นที่ท้ายเนื้อหาให้เลื่อนพ้นเมนูได้
- รองรับขอบปลอดภัยด้านบนและด้านล่างของ iPhone/Android รวมถึงหน้าเข้าสู่ระบบและหน้าหลัก
- ตรวจหน้าจอมือถือจริงทั้งแนวตั้งและขนาดแคบ พร้อมแก้จุดที่ยังล้นหรือซ้อนกัน

## รายละเอียดทางเทคนิค
- ใช้ `env(safe-area-inset-top)` และ `env(safe-area-inset-bottom)` ร่วมกับตัวแปรความสูงเมนูล่าง
- ใช้ `min-w-0`, `max-w-full`, grid แบบ responsive และ `overflow-x-hidden` เฉพาะโครงหน้าหลัก
- กำหนดความกว้างแผนที่/กราฟ/รูปภาพให้ยืดตาม container และไม่สร้างความกว้างขั้นต่ำเกิน viewport
- ตรวจผลด้วย build log และ Playwright ที่ viewport มือถือ
